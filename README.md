# Racing Sim 🏁

레이싱 시뮬레이션 게임 세 가지를 모은 저장소입니다. 모두 직접 운전하지 않고 **전략을 지시하는 시뮬레이션**입니다.

| 폴더 | 게임 | 실행 |
|---|---|---|
| `kart2d/` | **꼬마 카트 랠리**: 2D 버전. 동물 레이서들이 달리는 아기자기한 탑뷰 코스에서 감독 시뮬레이션 | `kart2d/index.html`을 브라우저로 열기 (휴대폰 지원) |
| `kart/` | **토이 카트 랠리**: 3D 카트 레이스 감독 시뮬레이션. 레이서·카트 세팅을 고르고 주행/아이템 전략을 지시 | `kart/index.html`을 브라우저로 열기 (휴대폰 지원) |
| `web/` | **GRID MASTER 웹판**: 피트월 순위표 화면의 F1 스타일 전략 시뮬레이션 | `web/index.html`을 브라우저로 열기 |
| `racing.py` | **GRID MASTER CLI판**: 터미널 전략 시뮬레이션 (아래 설명) | `python3 racing.py` |

**바로 플레이:** https://jordonpark.github.io/racing-sim/ (GitHub Pages, `main`에 올리면 자동 배포)

웹 게임들은 빌드 없이 HTML 파일 하나로 동작합니다. 3D 카트 게임은 three.js(r128)를 cdnjs에서 불러오므로 인터넷 연결이 필요합니다. 2D 버전은 외부 라이브러리 없이 동작합니다(글꼴만 Google Fonts).

### 꼬마 카트 랠리 – 레이스 해설

선택 화면의 **레이스 해설**을 켜면 꼬꼬 캐스터가 선두 변경, 추월, 스핀, 로켓, 랩 진입, 결승 같은 사건을 말풍선으로 중계합니다. 규칙 기반이라 외부 AI 호출이나 비용이 없습니다. **음성 읽기**를 켜면 브라우저 음성 합성(ko-KR)으로 읽어 줍니다.

### 꼬마 카트 랠리 – ComfyUI 그림

`tools/comfy_generate.py`가 ComfyUI로 레이서 초상화 8장과 장식(나무·덤불·버섯·선인장·바위·소나무·눈사람) 7장을 만들어 `kart2d/assets/`에 저장합니다. 게임은 이 폴더에 그림이 있으면 그 그림을 쓰고, 없으면 코드로 그린 그림을 씁니다.

ComfyUI가 켜진 PC에서(Windows 포터블 기준):

```
cd C:\AI\ComfyUI_windows_portable
.\python_embeded\python.exe <racing-sim 경로>\tools\comfy_generate.py
```

체크포인트는 SDXL 계열이 있으면 자동으로 고르고, `--ckpt 이름.safetensors`로 지정할 수 있습니다. 끝나면 `kart2d/assets`를 커밋해 올리면 GitHub Pages에 반영됩니다.

## GRID MASTER (CLI) 🏁

터미널에서 즐기는 레이싱 **전략** 시뮬레이션 게임입니다.
10대가 달리는 레이스에서 한 명의 드라이버를 맡아, 레이스 엔지니어처럼
랩마다 주행 모드·피트 스톱·타이어를 결정합니다.

- Python 3.8+ / 표준 라이브러리만 사용 (설치할 것 없음)
- Linux, macOS, Windows Terminal 지원 (ANSI 컬러)

## 실행

```bash
python3 racing.py
```

| 옵션 | 설명 |
|---|---|
| `--seed N` | 난수 시드 고정 (같은 레이스 재현) |
| `--auto` | 입력 없이 AI가 대신 진행하는 데모 |
| `--auto --season 3` | 3라운드 챔피언십 자동 진행 |
| `--laps N` | 랩 수 강제 지정 |
| `--speed 0.2` | 연속 진행 시 랩 간 딜레이(초) |
| `--no-color` | 색상 끄기 |

## 게임 모드
- **퀵 레이스**: 서킷·랩 수·팀·난이도를 골라 한 판
- **챔피언십**: 3~6 라운드, 드라이버/컨스트럭터 포인트 집계 (25-18-15-12-10-8-6-4-2-1)

## 레이스 중 조작

| 키 | 동작 |
|---|---|
| `Enter` | 다음 랩 |
| `1` / `2` / `3` | 푸시 / 노멀 / 세이브 모드로 바꾸고 진행 |
| `p` | 피트인 (타이어 선택) |
| `s` | 5랩 연속 진행 (날씨 변화·세이프티카·타이어 마모 시 자동 정지) |
| `f` | 끝까지 자동 진행 |
| `q` | 기권 |

## 시뮬레이션 요소
- **타이어**: 소프트/미디엄/하드/인터/웨트. 마모 70% 이후 급격히 느려지고 90% 근처에서 펑크 위험
- **날씨**: 레이스 중 비가 오고 그침. 레이더 예보 정확도 약 80%
- **연료**: 무거울수록 느림. 바닥나면 리타이어
- **주행 모드**: 속도 ↔ 타이어/연료/실수 확률의 트레이드오프
- **셋업**: 다운포스(서킷과 맞아야 빠름, 추월·타이어 마모에 영향)
- **추월**: 서킷 특성, 페이스 차, 타이어 상태, 모드, 공격성으로 확률 결정
- **사건**: 코스 이탈, 충돌, 기계 결함, 피트 작업 지연, 세이프티카(피트 손실 절반)
- **규정**: 비가 오지 않은 레이스는 드라이 타이어 2종 의무 (위반 시 +20초)
